# HV Equipment Assistant

HV 装备助手，用于装备强化预览、护符模拟、融合顺序规划和材料成本估算，并提供法师数据与伤害计算面板。

脚本提供模拟与规划，不自动提交游戏中的真实强化或融合操作。

## 装备强化

在角色装备页点击 **装备升级**，读取已装备的装备，调整目标锻造等级和 IW 等级，预览属性变化。

- 根据装备品质限制目标等级。
- 根据装备原名识别类型、材质和稀有材质，支持改名装备。
- 将预览增量显示在相关属性上，法师数据与伤害面板随预览更新。
- **读取等级**用于重新读取实际装备等级，**重置计算**用于恢复模拟设置。
- 点击 **计算材料**，汇总当前预览方案的材料、核心、世界之种和基础 Credits，可展开逐级明细。

没有提高目标锻造等级或 IW 等级时，不生成强化材料方案。

### 护符调整

支持读取实际护符，并模拟切换为无护符、小护符或大护符。可通过 **重置为实际护符**恢复当前装备的真实护符配置。

### 独立材料模拟

按 **X** 打开或隐藏独立的 **强化材料模拟**窗口，可自行选择品质、材料类型和目标等级进行估算。窗口标题会标明主世界或异世界。

## 装备融合

在主世界 Bazaar 的融合相关页面点击 **融合计算**。

### 导入装备

先导入主装备，再导入素材，支持两种方式：

- **页面快捷导入**：在游戏融合页面点击 **导入主装备**或**导入素材**；快捷导入的素材标记为库存装备。
- **手动导入**：在计算面板点击 **主装备**粘贴装备链接，再通过 **导入装备**菜单选择素材来源。支持多行链接及 `[url=装备链接]装备名称[/url]` 格式。

**导入装备**菜单包含：

| 选项 | 用途 |
| --- | --- |
| 库存装备 | 将实际装备作为库存素材参与计算 |
| 非库存装备 | 将其他实际装备作为备选素材参与比较 |
| P素材 | 添加各项基础值均为200的虚拟 Peerless 素材 |
| 自定义装备 | 按主装备的属性项目输入170～200的基础值，添加自定义素材 |

虚拟素材只用于模拟，不代表游戏库存中的真实装备。

主装备仅允许 **Legendary**；素材仅允许 **Legendary** 或 **Peerless**，并按以下条件匹配：

| 装备类别 | 必须相同 |
| --- | --- |
| 单手／双手武器 | 类别、武器类型 |
| 法杖 | 类别、法杖类型 |
| 盾牌 | 类别、盾牌类型 |
| 布甲／轻甲／重甲 | 类别、材质、部位 |

前缀、后缀不作为上述素材类型匹配条件。改名装备使用原名进行类型判断。切换为不同类型的主装备时，会清空旧类型素材。

重复导入会覆盖相同编号的旧装备，状态信息按实际新增数量显示。

### 计算与查看

1. 在列表中选择素材，查看主装备基础值增量、优秀度变化和融合费用；再次点击可取消选择。
2. 点击 **融合选择装备**进行一次手动模拟，或使用 **计算顺序／精确计算顺序**搜索素材顺序。
3. 查看简略、详细日志，并通过 **计算材料**汇总当前方案的需求。
4. 使用 **导出方案**导出装备顺序。在游戏融合页面使用 **导入方案**可按方案排序并标号。方案按主装备分别保存，融合后刷新页面会自动恢复剩余素材的排序，并保留原步骤编号；**清除方案**可恢复原始顺序，同时删除该主装备保存的排序记录。

精确搜索默认100秒，可修改时间并使用 **暂停**提前结束。限时搜索返回已找到的方案，时间耗尽不代表已证明全局最优。

主装备所有属性达到200后，不能继续模拟融合。

### 核心与粘合剂

融合使用对应类别的 Legendary 核心。每次融合按每项属性分别统计：

| 条件 | 普通材质 | 稀有材质 |
| --- | ---: | ---: |
| 素材该属性高于主装备 | 0个核心 | 0个核心 |
| 素材该属性低于或等于主装备 | 1个核心 | 5个核心 |
| 主装备该属性已达到200 | 0个核心 | 0个核心 |

每项尚未达到200的主装备属性，每次融合消耗10个对应粘合剂；普通与稀有材质一致。

### 撤销与重做

融合模块支持 **Ctrl+Z**撤销、**Ctrl+Y**重做，可恢复删除素材、导入主装备、导入素材、模拟融合及重置等操作。最多保留30步历史。

输入框中的编辑保留浏览器原有快捷键行为；读取或计算过程中暂不执行撤销、重做。撤销历史不跨页面刷新保存，也不会撤销游戏内已执行的操作。

## 材料与价格

强化和融合共用材料价格与库存服务。

- **价格来源**：市场买价、卖价、日／周／月／年均价，以及 HV Utils 保存价。使用 HV Utils 保存价需要已有对应缓存。
- **刷新市场价格**：按当前方案需要的材料读取，历史均价读取时显示进度。
- **刷新库存数量**：一次请求物品库存页面，更新脚本支持的全部材料库存。两边已打开的材料面板会同步更新。
- **使用库存**：决定是否从总需求中抵扣已有数量；读取库存本身不会消耗物品。
- **金额格式**：材料面板中，小于1m使用k，达到1m使用m，按两位小数精度显示。

主世界和异世界的库存分别缓存。更换游戏账号后，应刷新库存和价格再估算。

融合材料表格显示 **材料／核心、总需求、库存、需购买、单价、小计**。上方库存摘要只列出当前核心类型和方案涉及的粘合剂。

## 法师数据与伤害

装备页识别为法师配置时，显示法师数据与伤害计算面板，并读取强化、护符模拟后的属性。

- 法师面板显示综合分、熟练因素、反抵抗、穿抗所需macc和结论。
- 伤害面板可选择怪物种类、等级、主元素、DD和塔楼层数，并切换 IMP、暴击。
- 显示怪物血量、魔法与元素缓伤、怪物抵抗值、抵抗倍率与概率，以及 T2／T3 缓伤后伤害和最终期望。
- 结论以抵抗概率达到1%为过关条件；“过关”仍保留最低1%的抵抗概率。
- 默认按满级强化怪物计算。DD默认0，塔楼层数范围0～100；异世界两项均固定为0并禁用修改。

元素显示统一使用 **火、冰、雷、风、圣、暗**。

## 窗口与本地数据

窗口可通过标题栏拖动，点击或聚焦某个窗口会将其置顶。融合列表在桌面布局下独立滚动。

融合数据和部分设置保存在浏览器本地或脚本管理器存储中。**重置计算**保留已导入装备并恢复计算起点；**重置数据**会确认后清除计算面板中的融合主装备、素材、方案和日志。游戏融合页面保存的排序记录需通过 **清除方案**单独删除。

## 代码组织

脚本以单文件发布，按配置数据、公共工具、材料服务、公共界面、功能模块和启动入口分类。彩蛋列表集中在顶部数据区，装备页负责触发和显示。

提交问题时，建议附上脚本版本、所在页面、装备原名或链接、预期与实际结果，以及截图或保存的HTML，便于复现。
